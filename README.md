# FlightBooking Havayolu Seyahat (Asp.Net Core 9.0 Mvc)

## Projenin Temel Maksadı
FlightBooking, yapay zeka ve agentic mimarisinin turizm sektöründe uygulanabilirliğini göstermektedir. Proje, OpenAI tabanlı bir Travel Agent'ı aracılığıyla kullanıcının ilgili sorularını anlayarak, hava durumu, restoran, otel ve uçuş bilgileri gibi entegre seyahat verilerini sunmaktadır. Doğal Dil İşleme (Natural language processing), niyet algılama ve gerçek zamanlı (intent detection ve real-time) API entegrasyonu kullanılarak, seyahat planlama sürecini basitleştiren ve kişiselleştiren bir akıllı asistan sistemi geliştirmektedir. Böylece, yapay zekanın sektör spesifik uygulamalarının pratik implementasyonu gösterilmektedir.

FlightBooking; ASP.NET Core MVC, Entity Framework Core, OpenAI GPT-4o-mini, Google Maps API, Google Flights API, RapidAPI, Yahoo Weather API, MongoDB ve Machine Learning Regression Models kullanılarak geliştirilmiştir. Proje, intent detection, natural language processing, dynamic prompt engineering ve multi-tool agent orchestration gibi ileri düzey AI tekniklerini implementasyon etmektedir.
